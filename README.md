# 🏷️ PriceTagDetection — автоматическое распознавание ценников

Решение команды для хакатона **Lenta Tech LIFE HACK**.  
Система обрабатывает видео с робота, движущегося вдоль стеллажей, находит ценники, определяет их формат, извлекает текстовые поля (название, цены, штрихкод, дату и др.) и QR-коды, формирует структурированный CSV-файл, а также анализирует заполненность полок.

## 🧩 Основные модули (кратко)

### Детектор ценников
- **YOLOv8s** обучен на примерно 50 кадрах, извлечённых из предоставленных CSV.  
- Находит ценники на видео, возвращает bounding box.

### Выравнивание перспективы (`aligner.py`)
- Приводит ценник к плоскому горизонтальному виду (перспективная коррекция + поворот, если нужно).

### Определение формата (`template_classifier.py`)
- Геометрический fallback (по соотношению сторон) или обученный MobileNetV3 классифицирует ценник как `6x6`, `A4_horiz`, `A4_vert`, `A3`, `A5`, `MNC`.

### Извлечение зон (два режима)
1. **Фиксированные ROI** (`roi_extractor.py`) – по заранее размеченным координатам в `config/roi_templates.json`.  
2. **Адаптивный детектор полей** (`field_detector.py`) – YOLOv8n, обученный на синтетических ценниках, сам находит `barcode`, `price`, `product_name`, `id_sku` на выровненном изображении. *(Находится в стадии интеграции.)*

### OCR (`ocr_reader.py`)
- Использует **EasyOCR** (в Docker – PaddleOCR).  
- Специализированные методы: `read_id_sku`, `read_barcode`, `read_price`.

### QR-ридер (`qr_reader.py`)
- Multi‑stage чтение: `pyzbar` → CLAHE → adaptive threshold → fallback.

### Валидация (`validator.py`)
- Сравнивает штрихкод из OCR и QR, выставляет флаг при расхождении.

### Temporal Fusion
- `iou_tracker.py` связывает детекции между кадрами по IoU.  
- `best_frame_selector.py` (или `temporal_fusion.py`) выбирает для каждого трека лучший кадр по чёткости и наличию barcode.

### ✅ Готово и работает
- Детектор ценников обучен, находит ценники (требуется улучшение стабильности).
- Сам пайплайн от видео до CSV проходит полностью (детекция → трекинг → выравнивание → OCR/QR → CSV), но это пока скелет, и данные не все записываются (в виду неготовых других частей пайплайна).
- Конвертер CSV → YOLO‑датасет (с расширением соседними кадрами).
- Генератор синтетических ценников для field detector (надо исправить под горизонтальную ориентацию либо вообще удалить, т.к. нормально не работает).
- Ручная разметка **всех шести форматов** ценников выполнена в makesense.ai.
- Инструменты отладки (`check_roi.py`, `check_last_frame.py`, `convert_roi_to_horizontal.py`).
- Streamlit‑интерфейс (заготовка)

### ⚠️ Основные проблемы
1. **ROI‑зоны не совпадают.** Из‑за разной ориентации ценников после выравнивания фиксированные координаты не подходят.  
   *План: привести все ценники к единой горизонтали (aligner уже исправлен) и пересчитать `roi_templates.json` скриптом `convert_roi_to_horizontal.py`.*
2. **OCR не даёт читаемых результатов.** Пока зоны вырезаются мимо текста, EasyOCR нечего читать.  
   *План: после исправления ориентации и координат выполнить проверку `check_roi.py`, затем запустить полный пайплайн.*
3. **Field detector ещё не обучен.** Синтетика готова, но модель не обучена и не интегрирована.  
   *План: обучить `field_detector` на `field_synth` и подключить вместо `roi_extractor`.*

## 🚀 Быстрый старт

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/salimadze2005-beep/PriceTagDetection.git
   cd PriceTagDetection

   python -m venv .venv
   .venv\Scripts\activate      # Windows
   pip install -r requirements.txt
   Разместите данные

Поместите .mp4 видео в data/videos/.

Поместите .csv разметку в data/csv/.

Подготовьте датасет для YOLO
```bash
thon tools/csv_to_yolo.py
```
Обучите детектор (опционально)
```bash
python models/train_yolo.py
```
После обучения best.pt появится в models/runs/detect/....

Запустите обработку видео
```bash
python run_pipeline.py "data/videos/25_12-20.mp4"
```
Результат: CSV в папке results/.

Веб-интерфейс (Streamlit)
```bash
streamlit run ui/app.py
```
