# 🏷️ PriceTagDetection — автоматическое распознавание ценников

Решение команды для хакатона **Lenta Tech LIFE HACK**.  
Система обрабатывает видео с робота, движущегося вдоль стеллажей, находит ценники, определяет их формат, извлекает текстовые поля (название, цены, штрихкод, дату и др.) и QR-коды, формирует структурированный CSV-файл, а также анализирует заполненность полок.

## 🧩 Основные модули

### Детектор ценников
- Модель **YOLOv8s** обучена на кадрах, извлечённых из предоставленных видео и CSV.  
- Обнаруживает все ценники в кадре и возвращает bounding box.

### Классификатор формата
- **MobileNetV3** (или геометрический fallback) определяет тип ценника: `6x6`, `A4_horiz`, `A4_vert`, `A5`, `A3`, `MNC`.  
- Зная тип, мы применяем правильный набор ROI-зон.

### Выравнивание перспективы
- `aligner.py` находит контур ценника, вычисляет матрицу перспективного преобразования и делает ценник «плоским».

### Извлечение зон (ROI)
- `roi_extractor.py` загружает `config/roi_templates.json` и по координатам вырезает из выровненного ценника фрагменты для каждого поля.

### OCR
- `ocr_reader.py` — обёртка над EasyOCR (или PaddleOCR в Docker). Возвращает текст, а также специализированные методы для `id_sku` и `barcode`.

### QR-ридер
- `qr_reader.py` ищет QR-код в заданной зоне, извлекает штрихкод, цены, оптовые пороги.

### Валидация
- Сверяет штрихкод из OCR и QR, выставляет флаг при расхождении.

### Temporal Fusion
- Один и тот же ценник виден на нескольких кадрах. `iou_tracker.py` связывает детекции между кадрами, а `temporal_fusion.py` собирает наблюдения и применяет голосование (majority vote) для каждого поля. Это резко повышает точность.

### Аналитика полок (в разработке)
- Базовая реализация через поиск горизонтальных линий и подсчёт товаров. Демонстрирует дополнительную ценность решения.

# Текущий статус проекта и план дальнейших действий

## Что уже сделано

### 1. Детектор ценников
- Обучена модель YOLOv8s на реальных кадрах (26 изображений, 1 класс `price_tag`).
- Модель способна находить ценники на видео, хотя точность пока не идеальная из-за малого объёма данных.
- Для улучшения детекции можно будет автоматически расширить датасет с помощью трекинга (без ручной разметки).

### 2. Пайплайн обработки (все модули написаны и протестированы)
- **Загрузка видео и извлечение кадров** – каждые 2 секунды.
- **Детекция YOLO** – находит bounding box’ы ценников.
- **Трекинг по IoU** – связывает один и тот же ценник между кадрами (без OpenCV-трекеров, надёжно).
- **Выравнивание перспективы** (`aligner.py`) – делает ценник плоским, даже если он под углом.
- **Определение формата** (`template_classifier.py`) – пока используется простой геометрический fallback (по соотношению сторон), но скоро заменим на обученный MobileNetV3.
- **Извлечение ROI** (`roi_extractor.py`) – вырезает из выровненного ценника зоны для каждого поля (название, цены, штрихкод и т.д.) согласно `config/roi_templates.json`.
- **OCR** (`ocr_reader.py`) – временно EasyOCR, в Docker-образе будет PaddleOCR для максимальной точности.
- **QR-ридер** (`qr_reader.py`) – читает QR-коды и извлекает штрихкод, цены, оптовые пороги.
- **Валидация** – сравнивает штрихкод из OCR и QR.
- **Temporal fusion** – накапливает результаты с нескольких кадров и выбирает большинством голосов (majority vote) для каждого поля.
- **Генерация CSV** – объединяет все распознанные поля в итоговый файл.

### 3. Инструменты тестирования
- `tools/check_roi.py` – позволяет визуально проверить, правильно ли вырезаются зоны для заданного формата ценника. Уже выявил, что координаты для A4_vert требуют корректировки (зоны сохраняются, но частично не туда).
- `tools/csv_to_yolo.py` – конвертер CSV-разметки в YOLO-датасет (уже исправлен: группировка по номеру кадра, split по видео).

### 4. Синтетика для классификатора форматов
- Сгенерированы искажённые кропы ценников 6 типов (по 500 на класс).
- Классификатор MobileNetV3 пока не обучен – планируется обучить сразу после корректировки шаблонов.
